G-PSI.ai — paczka strony

Strona jest w katalogu www/
  cd www
  npm install
  npm run dev

Pięć prac leży osobno w katalogu głównym i w www/public/prosjekter/.
Na stronie głównej działają na żywo (wbudowane w stronę), nie jako zrzuty ekranu:
  simulator.html        demo, Fjordvik kommune, dane fikcyjne – suwaki stawek podatku
  utgiftsanalyse.html   demo, Fjordvik kommune, dane fikcyjne
  eiendomsskatt.html    demo, Fjordvik kommune, dane fikcyjne
  kalkulator.html       prototyp kalkulatora, Steigen (retningslinjer 2019)
  Laanndet.html         koncept, przykładowe ogłoszenia

Usunięte pliki ze starymi danymi:
  Steigen.html
  eiendomsskatt-steigen.html

simulator.html buduje skrypt tools/build_simulator_demo.py
z dist/simulator.html z repozytorium G-PSI-Web i danych z eiendomsskatt.html:
  python tools/build_simulator_demo.py --simulator ../G-PSI-Web/dist/simulator.html
